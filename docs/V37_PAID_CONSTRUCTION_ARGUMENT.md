# Conditional V37 construction and cost argument

Recorded before V37 fresh behavior, separately from any empirical outcome. This
does not change V36's fixed caps or erase its negative. V37's outer scheduler is
host-authored; no lineage-selected G8 or general L9 is asserted.

Let a target consist of `b` aligned three-slot blocks, each chosen from an archive
of four exact previously successful motifs. All slot operators are non-null and
each operator has an independent distinguishing reference witness. Candidate
quality is the total integer count of slots correct on all reference contexts.
Assume the actual native runtime can execute this interface under its fixed worker
limits, all four donor bodies survive, and the scalar receipt is exact.

For block `j`, zero its three slots while keeping all other slots as they were at
the start of that coordinate. Its measured score is exactly the contribution of
the other blocks. Every learned-fragment trial uses this same unchanged outside
body. The correct motif adds three. Every incorrect motif adds at most two, because
the four motifs are distinct and operator witnesses separate differing cells.
Consequently the greatest scalar score selects the correct motif. Include the
previously measured body among choices: if it ties with the correct trial, its
three cells also already match, so this inclusion cannot spoil the argument.

Other coordinates are independent, so subsequent edits cannot invalidate a block
already completed. Induction on `j` yields an exact target after at most `5*b`
construction evaluations (one block-null and four donor trials each). Stop earlier
if any evaluated body already solves the full task. One root, at most four paid
screens and one exact repetition yield at most `5*b + 6` calls. The external
equal-arm cap is `15*b + 6`, enough also for the point-only scheduler's five calls
per slot. Source deduplication never discounts repeat executions.

In the model every next independently rewritten combination is constructible,
regardless of how many prior positions change, unlike prefix-only induction.
Increasing block count ensures length-distinct semantic targets within this DSL;
four distinct targets per epoch produce four cohort first-solving events even if
some shorter motif behaviors were already discovered during acquisition.

This does not supply a constant lower discovery rate. With eight tasks per epoch
and external cap `15*b + 6`, the conservative first-solving/call lower bound is
`4 / (8 * (15*b + 6))`. It tends to zero as `b` grows. Even the tighter constructor
bound decreases as `1/b`. Counting finite positive windows cannot reverse this
asymptotic fact. Native work per evaluation also increases with body size; native
CPU, memory, storage and output limits eventually constrain the model.

Missing or incorrect motifs require paid point fallback and can erase the cost
advantage. Correlated coordinates, changed primitive meanings, poor reference
discrimination, scalar corruption, state loss or resource exhaustion invalidate
the assumptions. Four fixed primitive operators, fixed three-slot segmentation
and an externally authored composition curriculum remain. Nothing here establishes
primitive invention, endogenous planner acquisition, arbitrary environmental
adaptation, open-ended general L9 or independent L10.
