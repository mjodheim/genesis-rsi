# Conditional recursive archive continuation at fixed candidate cost

Recorded before V38 fresh behavior. This is a symbolic continuation argument with
explicit native limits, not a claim of physical infinite execution or general L9.
V38's outer coordinate scheduler is host-authored. The acquired objects are
successful executable programs reused as later construction operators.

Let `A(g)` be the four distinct exact native bodies discovered at level `g`, each
of length `2**g`. The external next-level task selects an ordered pair from `A(g)`;
its target is their concatenation. Four distinct such targets define `A(g+1)`.
Those choices are frozen independently of observed search behavior. Bodies at
different levels are semantically distinct in the admitted DSL because all cells
are non-null and the new length has executable behavior absent at older positions.

Suppose all of `A(g)` survives as successful archived source, references distinguish
each primitive operator, score is exact total matched cells, coordinates are
independent, and native workers can execute the current interface. For each half,
zeroing it measures outside-half contribution. Trying the four whole-body macros
on that same outside body has a unique greatest score: its exact target macro adds
`2**g`, while each different macro adds strictly less. Keeping a previously measured
body among choices cannot hurt: tying with that greatest score certifies the half
is already correct. After both coordinates, the candidate is exact.

At most two groups of five probes, one null call, four paid screens and one native
repetition are needed: sixteen calls. This holds regardless of which root screening
selects and which prior halves are rewritten. Each new successful full source is
eligible as a whole-program macro for the next level. Initial one-slot point
acquisition creates the four base values within the same fixed twenty-six-call
governance. Induction supplies four new descendants at every symbolic level.

The ancestor-only control removes `A(g)` and uses `A(g-1)` with half-sized macros.
Every new task has four such coordinates, so its constructive upper bound is
twenty-six calls. Both arms use the same full-history screening and coordinate
procedure. The finite frozen causal predicate is strictly lower aggregate cost
for latest macros in every seed/domain from level two onward; the upper bounds
alone do not prove strict advantage on every individual task. No such individual
strictness is claimed.

With four previously unsolved bodies in each eight-task epoch, the common external
cap gives discovery/charged-call lower bound `4/(8*26) = 1/52`. The archive's tighter
sixteen-call bound gives `1/32`. These bounds do not deteriorate with symbolic body
length. Solved bodies, donor generations, retained source and task interface size
keep increasing; the active four-value library is drawn from new acquisitions at
each level instead of remaining a fixed primitive-fragment library.

The growing archive is not an infinite physical resource. Native evaluation scans
all cells/contexts; executable source, CPU, outputs and storage grow exponentially
in level. Fixed CPU/memory/file-size/time limits eventually prevent physical
continuation. A positive charged-call model is not a positive asymptotic wall-clock
rate. The grammar admits only two-program recombinations of previously learned
values in four fixed primitive kernels; independent uniform wholesale rewrites
over an ever-larger flat alphabet would instead face V36's information bound.
Missing macros, changed kernels, correlated cells, poor witnesses, state loss or
resource failure break the induction. The external composition curriculum, native
guard and evaluator remain host-authored. There is no claim of an acquired G8
search policy, arbitrary-domain openness, general L9, independent L10 or completed
general RSI from this argument.
