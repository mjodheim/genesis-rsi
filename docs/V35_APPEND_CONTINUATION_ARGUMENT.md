# V35 continuation argument — explicitly scoped, Track B

This is a conditional induction about the public V35 append-extension environment,
not an inference of physical infinity from a finite trial. It uses unchanged G7
(`2e43fde55b4d17f9ab48be14322acb3d7f65dec8d3663cde068837d6d68b9ff4`),
the V35 source renderer, native discrimination witnesses and charged evaluator.
Codex authored both the apparatus and this argument for Anthony Mets. This is not
an independent maintainer's assessment, a new acquired policy or an L10 result.

## Assumptions

For each of the four native domains, the external environment maintains four
branches with different first operators. At epoch n each target extends its own
length n−1 target by exactly one operator from {1,2,3,4}. Each branch occurs in
every epoch. All five primitive outcomes, including null, are distinguishable on
the external context corpus. The evaluator reports the exact matched-slot count
to the host, while G7 sees only floored normalized quality and static descriptors.
Every previously evaluated program is retained. A branch's successful longest
body survives in the frontier. The native and policy workers complete within
their resource limits; completed-boundary recovery preserves the same history.

These are substantial environment assumptions. The curriculum, primitive set,
frontier partition and mutation generator are project-authored scaffolding.
Changing older slots, removing the correct frontier, ambiguous witnesses, native
timeouts or adding genuinely new operation families invalidates this argument.

## Root selection

Suppose all four length n−1 branch frontiers exist. Before this branch is solved
in epoch n, its old body matches exactly n−1 slots: the final missing slot returns
null. Another unspecialized length n−1 branch differs in its first slot and lacks
the final slot, so it matches at most n−2. A different branch already extended to
length n can match at most n−1. A tie with that longer body is resolved in favor
of the correct, shorter prefix. An exact screen requires all slots and therefore
already solves the task. Screening uses integer matched counts, so flooring
normalized quality for large n cannot reverse this choice.

## Search and the fixed evaluation cap

The selected prefix has every old slot non-null and the new slot null. Its four
single mutations of the new slot add one target axis. Mutations of old slots add
no axis. G7's candidate ordering therefore puts the four new-slot choices before
any old-slot mutation, in operator order. One is an exact extension.

Until an exact extension is evaluated, every root child is a wrong new-slot
choice with n−1 matches. Its depth-two child cannot improve on n−1 without
solving the task. G7's rule that drops the root requires a depth-at-least-two
eligible lead with strictly increased normalized quality. That condition cannot
hold for these depth-two children before a solve. Depth-three descendants have
no eligible children under the fixed depth-three cap and cannot trigger this
root-dropping rule as the selected eligible lead. Flooring quality does not turn
a non-increase in matched slots into a strict gain.

The first round has one root evaluation. Each subsequent round has at most one
other-parent evaluation followed by a root evaluation. In four rounds the four
root choices are therefore either evaluated or removed from the root's choices
because another parent already evaluated the same source. In the latter case a
correct removed choice has already solved the task. The search needs at most
seven calls to reach a correct root choice; allowing an additional call in a
batch that already solved still fits the remaining eight-call search budget.
Including the null probe, at most four frontier screens, at most eight search
calls and one actual solution confirmation gives at most fourteen evaluations.
The initial length-one epoch follows the same root-choice argument from null.

## Induction and positive discovery

The initial epoch produces four distinct successful one-slot programs. The root
selection and search argument yields each branch's next successful extension.
Retaining them establishes the hypothesis for the next epoch. Appending a
non-null slot changes actual behavior on its discriminating witness, so these
are four newly solved semantic bodies rather than source padding or rediscovery.
Their length and the number of successful bodies have no fixed global bound in
the mathematical model. With thirty-two tasks per epoch, discovery is bounded
below by 4/(32×14) = 1/112 per charged candidate evaluation in every epoch.

The archive thus has a constructive non-saturation argument *for this specified
family*, alongside a finite native execution assay and actual process recovery.
This is stronger evidence than extrapolating a positive twelve-epoch curve.

## Practical limits and falsifiers

The cap bounds candidate calls, not CPU, memory, input bytes or wall-clock time.
Each body execution and its contexts grow with n; source generation, archive
storage and policy descriptors also grow. The real finite machine and the native
worker resource limits cannot execute this mathematical process indefinitely.
Four native domains do not imply an expanding set of native domain families.
The operator language is compositional but narrow, and search policy G7 does not
evolve here. Independent replication and L10 remain outstanding.

Public apparatus tests check all four suffix operators at lengths 2, 12, 65 and
129, actual native extension beyond the historical 64-bit bound, isolated/local
wire equivalence, complete cost, retained ancestry, missing-frontier failure,
ambiguous-witness rejection and completed-boundary recovery. These tests probe
assumptions and counterexamples; finite tests do not prove induction by themselves.
The proof obligation remains the stated argument and the pinned implementation.

Additional assumption audits were written during the fresh campaign in the
separate `tests/test_v35_continuation_counterexamples.py`; they do not modify the
frozen apparatus tests or selection population. Native screening at length 2,001
shows why raw matched counts are necessary: wrong and correct prefixes both have
normalized quality 999, while their raw counts are 1,999 and 2,000. A direct
byte-exact G7 test confirms that this floor tie cannot trigger its strict-gain
root-dropping rule. An actual native prefix-rewrite counterexample retains all
four branches yet solves no length-twelve task: at most four of twelve slots
match under depth three. Thus the append-only assumption is a demonstrated
restriction, not merely a hypothetical disclaimer.

Consequently a positive V35 assay may establish sustained expanding archives in
this append-extension model. It does not by itself discharge a general Genesis
L9 gate that demands discovery outside the project-authored extension curriculum.
