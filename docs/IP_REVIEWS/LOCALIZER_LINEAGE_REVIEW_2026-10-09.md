# Self-rewritten fault localizer lineage — 9 October 2026

Anthony authorises moving self-revision from configuration text to executable code of
Genesis itself, keeping an external economical model as the writer, with every generation
judged on cases it was not shown and with earlier verified attempts kept as memory for
later generations. Under the standing PUBLIC_AGPL_COMMERCIAL_OPTION decision, publish a
bounded lineage in which the fault localizer (a small Python module mapping a failing
test report and a read-only source tree to at most six suspect locations) is rewritten by
the model from its own measured misses, executed only inside a network-less container,
and scored without any model against the developer fixes of development cases.

Review precedes implementation. AI development assistance is as recorded in
`docs/AI_ASSISTED_DEVELOPMENT_PROVENANCE.md`; model-written modules keep their model and
call provenance and are stored as data, never imported by the host. No third-party code is
copied into the authored mechanism; Defects4J cases and their fixes remain upstream data
under their upstream licences and are not redistributed here beyond case identifiers,
line numbers and short excerpts already used by earlier trials. Software AGPL-3.0-only;
prose follows LICENSE_POLICY.md. Alternative licensing is subject to actually controlled
rights. No patent-first, trade-secret, confidential-third-party or embargo reason
identified. Program search guided by a language model and measured by an automatic
evaluator is a known technique; no novelty is asserted for it.

No frozen experiment changes. The repair-bench split is unchanged: held-out cases are
neither checked out nor compared with their fixes by this lineage, and their fixes stay
unextracted. A localization score is a proxy, not a repair rate. No general RSI claim
follows from any outcome of this lineage.
