## V28 L6 — three automatic causal improvement transitions

The exact G3 controller automatically discovers G4 exploration/persistence, then
G4 discovers G5 proposal ordering, then G5 discovers G6 scheduling. No human
chooses the winner between those generations. The fixed family has 81 semantic
programs with four declared comment-layout variants each; layouts introduce no new
behavior. Each generation locks earlier acquired genes. Selection uses the full
disclosed public population and an external evaluator.

All nine predicates pass on the 48 new represented graph contexts. Utility is
lexicographic solved tasks, summed quality, negative requests, negative rounds.
The table reports cumulative fresh populations; the later stage does not exclude
earlier failures or previously acquired capabilities.

| Transition | Cumulative tasks | Parent solved / quality / requests / rounds | Successor solved / quality / requests / rounds |
| --- | ---: | --- | --- |
| G3 → G4 | 24 | 2 / 19160 / 164 / 94 | 8 / 20480 / 192 / 108 |
| G4 → G5 | 36 | 8 / 27980 / 300 / 168 | 20 / 32480 / 252 / 144 |
| G5 → G6 | 48 | 26 / 43380 / 348 / 198 | 26 / 43380 / 342 / 198 |

The third gain is **six saved represented evaluations**, with quality and rounds
unchanged. The first gain spends more evaluations for more solved tasks; this is
not a general efficiency claim. Every new component's fresh ablation loses the
corresponding cumulative utility. Prior solved capabilities remain solved, and
all descendants retain the four consumed V26 native tasks at quality 1000.
Those native runs are retention, not fresh native transfer for L6.

The qualified earlier G2 fails bootstrap discovery. Removing G4's persistence
prevents qualified G5 discovery. Removing G5's ordering increases G6 discovery
from 1 request/1 round to 3 requests/2 rounds. Removing older persistence during
G6 discovery ties; that tie remains descriptive, not a causal victory. The claim
is a nearest-acquisition causal chain, not necessity of every old mechanism on
every later task.

## V30 L8 — choosing which part of the improvement pipeline to repair

G6 discovers G7's pure measured-bottleneck selector in 4 meta evaluations and
3 rounds. A matched G6 controller with only its latest scheduling acquisition
removed discovers the **same** G7 in 5 evaluations and 3 rounds. The causal gain
is lower discovery cost, not exclusive reachability.

The selector sees only counters from revealed executions and static proposal
regions. It chooses exploration, proposal generation, scheduling or identity.
The common repair operator restores the chosen gene on a faulted disposable copy
of its own qualified pipeline. It sees no task identity, fault label, graph,
unrevealed oracle, file or credential. All controllers receive the same measured
probe, one target call, one repair opportunity, and equal per-search external caps.

All 324 examined public contexts are archived, including **230 ineligible
contexts**, without presenting their selection as fresh evidence. All eight
