## Executable domain and task construction

Four materially different actual kernels: relational SQLite queries, regular
expression transforms, structured JSON processing and zlib decompression.
Bodies are canonical finite sequences of native operators, with no global fixed
sequence-length catalogue. Missing cells return null. Appending another non-null
operator changes executable behavior on that cell. The admitted primitive set
is host-authored; learned executable fragments are lineage state, not host-added
primitive semantics or a new policy generation.

Each domain has four target branches rooted in distinct first operators 1–4.
Every epoch appends one seeded operator to each branch. Epoch n targets length n.
All four branches occur eight times in a prospectively shuffled thirty-two-task
epoch. Context bytes vary on each task. The actor sees neither target operators,
branch labels, expected answers, input/output pairs nor future task identity.
This structured append-extension curriculum is project-authored and a substantive
assumption of every result; it is not arbitrary environmental change.

The external evaluator executes the candidate on every component/context and
counts a component correct only when all its context cases match. Distinct
operators must have a measured distinguishing witness in the context corpus.
It reveals total matched-component count and normalized quality to the host;
G7 receives normalized quality and static candidate descriptors only. An exact
solve requires every component, including all paid screening probes, to pass.

## Controls, archive selection and cost

Three arms use byte-exact G7 search with the same fourteen-evaluation cap,
eight-round cap, parallelism two and local mutation depth three:

- Archive retains every evaluated descendant and screens up to four successful
  frontiers, one per actual first-operator branch, before searching.
- Greedy retains the same full evidence but may screen only its most recently
  successful body. Historical alternatives cannot be proposed in this arm.
- Cold uses no historical body in construction or screening.

Every arm evaluates the null root once. Screening evaluations are fully charged,
including failures. Choose the observed candidate with most matched components;
break equal-quality ties by shorter effective body, then source digest. The
remaining search budget is twelve minus actual screening calls. Reserve one more
call for exact-solution re-execution: root + screening + search + verification
never exceeds fourteen. Candidate metadata/decision calls remain separately
bounded by the existing G7 ABI and eight rounds; report them rather than claiming
they cost no CPU. Screening stops on an exact solve; all executed probes remain
in the archive. Search children change one cell to another native operator.

Keep first-solving semantics distinct from first-seen source, previously partial
source, rediscovery, repeated execution and new improvement machinery. Canonical
genomes omit trailing nulls; semantic identity includes the actual kernel and
effective operator sequence. Witness checks justify identity within this DSL,
not general program equivalence.

## Durability and recovery

Reserve the full task cost before execution in an append-only hash-chained journal.
Separate epoch journals bind the prior epoch head and complete retained history;
do not silently reset archive state at epoch boundaries. Commit immutable raw
epoch evidence, summary and completion after verifying every receipt. Pending
tasks remain quarantined, with their full unknown cost charged; no free retry.
Resumption occurs at completed task boundaries only. No mutable completion index.

Reconstruct between epochs in fresh processes. One declared mid-epoch stop after
task sixteen also reconstructs from disk. The interrupted prefix must not execute
again. Full replay verifies inputs, all outputs against external references,
actor decisions, complete accounting, ancestry, archive retention and ledger heads.
Replay is not fresh evaluation or independent replication.

## Frozen finite predicates and scope

The native sustained-archive assay is positive only if:

1. All tasks, arms, native executions, identities, caps and recovery/replay verify.
2. Archive gains at least four previously unsolved semantic bodies in every domain
   and seed in every one of the final six epochs; rate is at least 1/112 per actual
   charged evaluation in each such epoch. Preserve zero-rate and failed windows.
3. Archive size and number of first-solving behaviors strictly increase in each
   domain/seed in every epoch, with at least four retained branches and actual
   rediscovery and fresh-process recovery demonstrated.
4. Archive strictly beats both cold and greedy on aggregate exact coverage in each
   seed/domain, with no greater charged cost than cold in aggregate.
5. Length grows through twelve and behavior/ancestry witnesses verify; neither
   source padding nor repeated target contexts count as new semantic behavior.

Failure remains a complete retained negative. No seed filtering, changed
threshold, rescoring or second fresh attempt is allowed. Passing these predicates
reports only the scoped native sustained-archive outcome. Report per-domain,
per-seed, per-epoch coverage, first-solving behavior, rates, cost and controls.
