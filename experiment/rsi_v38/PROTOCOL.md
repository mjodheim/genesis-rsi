## Curriculum and acquired tools

Four actual V35 native kernels and independently constructed references remain.
Epoch zero targets the four distinct one-slot operators. In each next epoch,
sample four distinct targets by concatenating two bodies from the previous
epoch's four targets. No branch label, correctness, observed behavior, distance
or solvability filters sampling. Shuffle each epoch's four bodies repeated twice.
Every epoch doubles interface length; old positions can change. The curriculum
grammar is host-authored and closed under two-program composition. It is not
arbitrary environmental change or invention of new primitive meanings.

Only previously successful executable bodies are eligible donors. For current
length `n`, `archive` uses successful whole bodies of length `n/2`. Their exact
operator vectors become state-owned construction macros. `archive-ancestor`
uses only successful whole bodies of length `max(1,n/4)`, removing the most recent
macro acquisition; its whole-body retrieval is identical to archive. `greedy`
may extract aligned `n/2` fragments only from its latest successful body. `cold`
has no historical retrieval or macros. All evaluated sources, not just successes,
remain preserved. Record successful donor acquisition and exact source ancestry.

## Equal fixed governance

All four arms receive twenty-six native candidate executions per task, independent
of interface length. Reserve the full cap before behavior. One null call, at most
four paid screens and one exact repetition are charged. Use V37's scalar coordinate
constructor with the admitted macro width; no more than the remaining paid calls.
One-slot interfaces use point construction. If no macro exists, use point
construction; missing completion of a probed macro coordinate triggers point
fallback, entirely charged. Budget exhaustion stops cleanly; pending instrument
reservations are quarantined without free retry.

The scheduler is host-authored, with zero G7 policy calls. Acquired whole-program
values change the later candidate generator, not the external evaluator, loader,
accounting, permissions or success criterion. Scalar planning uses raw total count
only; hidden targets/references and per-slot correctness never enter selection.
Actual candidate bodies run in isolated native workers in fresh mode. Native
CPU/memory/output/time limits remain unchanged; failures must be retained.

## Conditional continuation, not finite-only open-endedness

If all four previously successful whole-body macros survive, each two-macro target
is constructible with two zero-and-four-donor probe groups. With root/screens and
confirmation, that is at most sixteen native calls. The previous-generation
macro ablation uses four smaller coordinates and at most twenty-six calls. Both
remain within equal fixed governance. Newly solved full bodies then supply the
next generation's four macros, so induction repeats at arbitrary symbolic depth.
Four new distinct length-doubled behaviors per eight-task epoch imply a charged
discovery lower bound of `4 / (8*26) = 1/52` in this model; library cardinality stays
four per level, while executable macro size and retained diversity keep growing.

The model assumes complete library retention, independent slots, distinguishing
references, exact scalar feedback and sufficient actual native resources. Body
size/native CPU/storage grow exponentially in depth; fixed worker limits ultimately
bound physical continuation. Constant candidate-call rate is not constant native
work or wall-clock rate. The fixed composition curriculum and host scheduler remain
explicit. Passing reports a scoped recursive-macro archive outcome; it does not
by itself qualify a new G8 policy, general L9, independent L10 or RSI completion.
