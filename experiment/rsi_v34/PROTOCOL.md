# V34 — continuing archive under fixed external governance

Declared before enabling implementation and before any V34 development behavior.
This successor carries the same archive across separately committed epochs instead
of restarting a fixed bank. It expands from integer arithmetic (epoch 0), to text
rewriting (epoch 1), sequence transformation (epoch 2), and record transformation
(epoch 3). Subsequent epochs extend independently generated target programs and
revisit old branches. All task construction is fixed now, without outcome filtering.

## Attribution and authority

Unchanged qualified G7 controls search and measured probe/identity root selection.
Program grammar, quality functions, witness inputs, retrieval, task generator,
epoch ledger and continuation are project-directed Track B apparatus, not acquired
G8 machinery. All earlier freezes, negatives and G7 bytes remain immutable.
No scientific external model call, target/input/task-label disclosure to a policy,
new credential, permission, evaluator change or policy-owned ledger is permitted.
Task authorship is project-controlled; no external independence is asserted.

Every task pays identity, two distinct candidate probes and one controller call,
plus at most ten search requests, eight rounds, parallelism two and depth three.
Both actual task cases and a fixed public behavior-witness batch are evaluated
inside that single candidate call. Witness outputs support **observed behavior
diversity**, not a proof of whole-domain semantic equivalence. They enter archive
statistics, not the selector or hidden-task quality. Every call has the inherited
1 CPU-second / 512 MiB / 3 wall-second worker boundary.

Keep every source and failed proposal. Adaptive retrieval ranks same-domain past
successes by nearest past identity quality to current revealed identity quality,
then recency, success count and source hash. Re-evaluate the top two. Use G7 to
start from the best probe only when its observed quality exceeds identity; otherwise
start from identity. A recency control ranks only by success recency. The greedy
control exposes only the latest successful descendant per domain, with one local
probe filling the second slot. Cold exposes no past program and probes two local
neighbours. All arms choose an improving probe root from actual observed work;
greedy is not forced to start from a worse root. All probe outcomes count in final
solutions even when not chosen. Previously paid sources are excluded from search.

## Public development and first prospective prefix

Publish the complete fixed implementation pilot on seeds 503 and 887, epochs 0–3,
all four arms; 120 consumed public tasks per arm. No parameter sweep or winning
algorithm selection occurs. Preserve any pilot failure and use a separately
labelled successor for outcome-driven changes.

Fresh seeds are 786433, 1048583, 1310719. The first measured prefix is epochs 0–7:
156 tasks per seed, 468 per arm, all four arms. Each seed/arm starts empty once,
then carries its exact history across all eight epochs. Every epoch must bind its
task bytes, the original scientific freeze and the previous complete receipt.
Reserve all work before behavior; stop after three complete tasks and reconstruct
from disk. Completion, raw, verdict and reservation are single-assignment files.
Any incomplete reservation stops the programme without a free retry or hidden
task deletion. Publish every epoch, including a negative one, before continuation.

The generator supports subsequent epochs with the same source and governance;
continuation is explicit and separately reserved. The pure-source representation
has a declared 128-instruction resource capacity, not an infinite expressivity
claim. Capacity exhaustion is a stopping reason, never a positive discovery.

## Measurements and stopping rules

For every arm/seed/epoch report solved cases, full charged cost, source archive
size, observed behavior diversity, branching, rediscovery of prior successes,
strictly new solving behaviors and their rate per 1,000 charges. Count as new only
a behavior-witness hash never observed before, including as a partial proposal.
Report rates without integer rounding that can conceal small positive rates.

The first-prefix **measured continuing archive** qualification requires complete
evidence/recovery and retained branching; strictly growing source and observed
behavior archives; at least one new solving behavior per adaptive seed/epoch;
strictly more adaptive solves than cold and greedy, no per-seed cold regression,
and no greater total cost than cold. Report recency comparison separately.
These thresholds are declared before the pilot. Preserve every failed predicate.

After the first prefix, evaluate the same growth/discovery conditions at each new
epoch. Zero new solving behaviors, capacity exhaustion, incomplete evidence or a
governance mismatch suspends the positive monitoring status. No automatic revision
of thresholds, representation, seed, target author or evaluator is allowed.

**A finite observed prefix does not pass open-ended L9 or prove an asymptotically
positive discovery rate.** The programme has continuable, externally governed
measurement and expiring observations; it does not fabricate an infinite result.
L10 remains future genuine external fork evaluation, reproduction and adversarial
audit. No external person is contacted in this work.
