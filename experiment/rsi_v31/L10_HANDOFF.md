# Independent reproduction and adversarial-audit packet

This packet prepares an independent execution; no maintainer, private bank,
reproduction or adversarial audit has been received. The implemented private-bank
runner covers finite rotation/XOR transducers around unchanged G7. It is a
replication rehearsal interface, not an externally validated general RSI claim.
Broader independently maintained tasks and a sustained L9 measurement programme
remain required by `docs/RSI_GENERAL_SUCCESSOR_MAP_2026-09-23.md`.

## Roles and trust, agreed before any private candidate execution

Identify a real task maintainer outside the project, a separate reproducer and a
separate adversarial auditor. Record role, conflicts and independence from
Anthony Mets, project-controlled AI agents and each other. Identity/independence
is verified by people out of band, not inferred from a newly generated SSH key.
No one has been contacted by this packet. Do not accept external copyrightable
code/banks into this public repository without the rights arrangement in
`CONTRIBUTING.md`. Private tasks and their execution journals stay with the
external custodians, never in public branches, CI logs or PR attachments.

The project supplies the published `PROJECT_PIN.json`. Clone the repository and
checkout its exact `checkout_commit`, preserve full Git ancestry, use its exact
Python version, and verify every manifest byte. The export command is:

```
python -m experiment.rsi_v31.independent export --output /secure/PROJECT_PIN.json
```

The maintainer supplies a JSON task bank (24–1024 tasks) in the `bank.validate_task`
schema, ordered by window, without duplicate task IDs. Author all tasks before
running any candidate. Do not select seeds/tasks after a pilot on the qualified
lineage. Reserve a fresh population for any substantive adapter change.
Each task contains `task_id`, `window`, `family` (xor/rotation/affine), `width`,
`inputs` and a private `target` with `width`, `rotation`, `mask`. Width is 2–64.
The actor does not receive the target, inputs, expected outputs or task ID.

Fill `BANK_COMMITMENT.template.json`, including the SHA256 of the **exact bank
bytes**, project pin digest, own identity, domain description and conflicts.
Replace nulls only with truthful assertions. Keep this commitment outside the
repository. Sign before first execution and retain a timestamped custody record:

```
ssh-keygen -Y sign -f /secure/maintainer-key -n mira-genesis-l10-review-v1 /secure/BANK_COMMITMENT.json
```

Supply independently configured allowed-signers lines for the three identities,
each with a distinct externally owned key. Example format (no keys are supplied):
`maintainer-id namespaces="mira-genesis-l10-review-v1" ssh-ed25519 PUBLIC_KEY`.
Trust must not be taken from a task-bank payload or generated by the lineage.

## Primary run and reproduction

Run in a private external workspace, with a previously nonexistent output path:

```
python -m experiment.rsi_v31.independent run \
  --project-pin /secure/PROJECT_PIN.json \
  --private-bank /secure/TASKS.json \
  --bank-statement /secure/BANK_COMMITMENT.json \
  --allowed-signers /secure/allowed-signers \
  --identity maintainer-id --output /secure/primary
```

The runner verifies signature, payload, pin and runtime before any evaluation.
It records all archive/greedy/cold arms, failures, sources, costs and journal
heads. Never reuse an output directory after a failed attempt. Mid-task debt
is quarantined; automatic continuation is only at completed task boundaries.

The independent reproducer obtains the original privately held bank/commitment
from the maintainer, checks the commitment predates first execution, and runs
the same command in their own clean checkout/runtime and separate output path.
The two `REPORT.json` documents must match exactly. Then fill and sign
`REPRODUCER_ATTESTATION.template.json`; signatures use the same namespace.

## Adversarial audit and what remains outside the machine gate

The auditor independently inspects source and receipts, verifies identity and
conflicts, bank custody, unchanged policy/evaluator, all tasks/negative results,
budget accounting, archive heads, authority separation, leakage and rights.
They attempt tampering, missing-task/negative deletion, key substitution,
pending-task retry and scope inflation. Record failures rather than returning
all-true by default. Fill/sign `AUDITOR_ATTESTATION.template.json` only after
the actual audit. Verification command:

```
python -m experiment.rsi_v31.independent verify \
  --project-pin /secure/PROJECT_PIN.json \
  --primary-report /secure/primary/REPORT.json \
  --reproduction-report /secure/reproduction/REPORT.json \
  --reproducer-statement /secure/REPRODUCER_ATTESTATION.json \
  --auditor-statement /secure/AUDITOR_ATTESTATION.json \
  --allowed-signers /secure/allowed-signers \
  --maintainer-identity maintainer-id \
  --reproducer-identity reproducer-id --auditor-identity auditor-id
```

A valid SSH signature establishes control of an externally trusted key. It does
not establish genuine independence, novel task authorship, absence of conflicts,
adversarial adequacy or broad-domain scientific validity. The verifier therefore
reports packet consistency and preserves `l10_independent_passed: false` pending
external human assessment against the original ceiling. A finite successful
transducer reproduction cannot close L9 or establish global RSI.
