# V40 development — conditional anti-extinction frontier

V39 increased novel solving behavior on consumed public data (35 versus V35's 32)
but reduced solved tasks to 94/120, below the same cold control at 95/120. V40
therefore keeps the V39 novelty-yield frontier only as a local recovery mechanism.

The V35 curriculum, grammar, witnesses, G7 controller, search caps, two paid probes,
four arms and fourteen-evaluation maximum remain unchanged. On adaptive tasks the
normal V35-style pair of compatibility memories is used unless the previous three
observations from the same domain produced no new solving behavior. Only then is
the second slot replaced by the deterministic novelty-yield frontier. An
equal-quality frontier can become the search root only while that stagnation
predicate is true.

This is development on already-consumed seeds 503 and 887. No fresh V40 seed is
executed here; L9 and L10 remain false whatever the pilot outcome.
